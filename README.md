# Portugal Curioso

Web visual en español con 120 curiosidades de Portugal: historia, fútbol, política, cultura, gastronomía y datos random. Incluye un botón animado que revela una curiosidad por clic y enlaces a las fuentes. Los 120 datos se barajan y no se repiten hasta agotar la colección durante la visita. Quiz con un banco de 24 preguntas, partidas aleatorias de 10, explicaciones, puntuación y récord local.

## Abrir

Abre `index.html` con tu navegador. No requiere instalación ni servidor. Los textos, el juego y la fotografía funcionan sin conexión; las fuentes tipográficas de Google y los enlaces a las fuentes requieren internet. Si no hay conexión, se utilizan las tipografías del sistema.

## Archivos

- `index.html`: estructura de la página.
- `style.css` y `portugal.css`: diseño y adaptación a móviles.
- `app.js`: contenido original e interacciones.
- `datos-extra.js`: 80 curiosidades adicionales con sus fuentes.
- `quiz.js`: juego de preguntas.
- `lisboa.jpg`: fotografía de Lisboa.
- `favicon.svg`: icono del sitio.

## GitHub Pages

1. Crea un repositorio y sube el contenido de esta carpeta a su raíz, con `index.html` en el primer nivel.
2. En Settings → Pages, elige Deploy from a branch.
3. Selecciona la rama main y la carpeta / (root), y guarda.
4. GitHub mostrará la dirección del sitio cuando termine la publicación.

Repositorio: https://github.com/andres222aq-coder/portugal-curioso
